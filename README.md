# Call Analysis Application

Приложение на Python для анализа качества разговоров людей с голосовыми роботами. Проверяет корректность диалогов с помощью нейросетей, рассчитывает метрики и формирует готовые Excel-отчёты.

> **Примечание:** Это портфолио-версия проекта. Все реальные данные заменены на заглушки. Промпты для LLM находятся на платформе Yandex Cloud.

## Возможности

- **AI-анализ разговоров.** Отправка пакетов транскрибаций в LLM (Yandex Cloud). Нейросеть по заданным промптам находит ошибки и определяет корректность диалога.
- **Расчёт метрик.** Вычисление контактности, CPL и других показателей с помощью `pandas`.
- **Формирование Excel-отчётов.** Генерация сводных таблиц с формулами, цветовой индикацией (успешные результаты) и комментариями к ячейкам через `openpyxl`.
- **Пакетная обработка.** Асинхронная работа с файлами в отдельных потоках, чтобы интерфейс не зависал во время долгих запросов к API.
- **GUI на Tkinter.** Удобный интерфейс с прогресс-баром, логом выполнения, очередью файлов и возможностью отмены.

## Стек технологий

- **Язык:** Python 3.10+
- **Данные:** Pandas
- **Excel:** OpenPyXL
- **Интерфейс:** Tkinter
- **AI:** OpenAI SDK (Yandex Cloud AI Studio)
- **Интеграции:** Взаимодействие с Yandex Cloud API (HTTP-запросы, JSON)

## Особенности реализации

- **Отказоустойчивость API:** Обработка ошибок авторизации, парсинг невалидного JSON от нейросети, повторная попытка извлечения данных регулярными выражениями.
- **Работа с файлами:** Фильтрация тестовых номеров, разделение общего отчёта на отдельные файлы по ботам, обработка пустых и некорректных данных.
- **Безопасность:** Конфигурация через `.env` (ключ API и другие важные данные не хранятся в коде).
